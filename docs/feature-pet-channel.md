# Feature：桌宠播报（agent 驱动）

> 状态：**v3 已实现；v4 已实现（新增每日插画，MVP）**。
> 本文只讲**用户看到什么、要满足什么**；技术落点、时序、改哪些文件见
> [桌宠通道架构](architecture-pet-channel.md)。
> 插画单独成篇：[每日插画](feature-pet-illustration.md)；给模型的写法见
> [prompt 指南](prompt-pet-illustration.md)。

## 一句话

判断层把今天说完，**怎么说、播什么，交给 agent**：桌宠说一句有温度的话、配一段动画；
v4 还可以在旁边放一张当天生成的 3:4 插画。

## 为什么

v2 试过让管线自己播：取 `summary` 首句、按进度套五档动画。能跑，但**死板**：

| | 管线直接播（v2） | agent 播（v3） |
|---|---|---|
| 台词 | `summary` 首句，天天一个模子 | agent 自己写：可以安慰、催一句、吐槽、点名某个动作 |
| 动画 | 按进度固定五档 | 106 段任选，可以按**情绪**挑而不是按数字 |
| 配图 | 没有 | 27 个表情包 + 当天生成的插画 |
| 上下文 | 只有 `Judgment` | 还能看到素材、历史、今天星期几、你昨天说过什么 |
| 语气 | 模板 | 会变，不会每天都是同一句腔调 |

一句话：**随机性和语气不该由模板决定，该由判断「今天该用什么口气」的那个角色决定。**

## 用户看到什么

管线跑完，`archive/2026-10-30/pet_task.md` 落一份简报；agent 读完，自己写一句：

> 工资到账先扣一小份藏起来，剩下的花着才不慌。

配「收红包」这段动画（不是按进度算出来的「数金皱眉」）——因为今天该庆祝，不该皱眉。

v4 还会在旁边放一张 3:4 插画：同一件事的**一个瞬间**；图里可以用一个关键数字 /
一句短台词点睛，但绝不做流水账或报表。图和话各自独立，但情绪对齐。
见 [每日插画](feature-pet-illustration.md)。

## 范围

### 做

- 每天一份**简报**：今天的事实 + 可发挥的空间 + 播报命令；
- agent 写一句 **≤60 字**的台词，挑一段动画 / 一个表情包；
- 可选配图：当天生成的 3:4 插画（单独 feature；没有就只播文字）；
- 播报失败**不影响归档**；没人播就静默，不打扰；
- 默认不开启，配了 `PET_BASE_URL` 才写简报。

### 不做

| 不做 | 原因 |
|---|---|
| 不做角色素材库 | 角色和参考图由 `dsh-pet` 维护；StepLedger 不复制、不改角色设定 |
| 不做定时调度 | 调度归宿主 agent；没有 agent 时才用 cron 兜底 |
| 不做多宠物轮播 | 先 `PET_ID` 单选；多宠物是另一个 feature |
| 不做图里的流水账 / 报表 | 图只负责一个瞬间；明细在气泡和报告里 |
| 不把播报写进归档正文 | 只追加 `pet_said.md` 供次日去重 |

## 怎么开

`.env`（gitignored）里配三行就够：

```bash
RENDER_CHANNELS=console,pet       # 加 pet 才写简报
PET_BASE_URL=http://127.0.0.1:<port>/dsh-pet-7340
PET_ID=main
```

可选：

```bash
PET_ANIM_TIERS=...                # 只影响简报里的档位建议和 --auto
ILLUSTRATION_API_KEY=...          # 配了才生成插画；不配就只播文字
```

`.env.example` 只有 fake 占位。没有 `PET_BASE_URL` 时整条路径零网络、零新文件。

## 验收

1. **配了就能播**：配好 `PET_BASE_URL` / `PET_ID` 后跑管线，写 `pet_task.md`；
   管线本身不碰宠物、不发请求。
2. **agent 真的能播**：读简报后用 `pet_play.py` 播一句；`/state` 的 `say.text`
   与发出的文本一致，`anim.name` 等于指定动画，锁已释放。
3. **没配就零影响**：不配 `PET_BASE_URL` 时，产物与现状一致、零网络、无 `pet_task.md`。
4. **失败不拖垮**：dsh-pet 没运行 / 投喂断网 / 读回不一致，只影响播报，归档照常。
5. **有图更好，没图也能播**：配了插画 key 时气泡带图；图服务失败退回纯文字。
6. **台词像人话**：≤60 字、不改数字、不复述总结；人工看三天，不是同一个句式。
7. **渠道独立**：只开 pet 渠道也能跑，不依赖 `report.md`。

## 未决问题（产品）

1. 无人值守的自动播报要不要也交给模型润色？现在坚持确定性（不烧 token、可预测）。
2. 简报要不要带上前几天的判断，让 agent 说得更有连续性？
3. 多宠物：先按一只配，还是轮流说？
4. 播报失败要不要弹系统通知（现在只给退出码）？
5. 插画要不要给 agent 留改画面的入口？
6. 图要不要也给 console / IM？
